# Imran Nadeem — AI/ML Engineer Portfolio

A responsive dark-theme portfolio built with plain HTML, CSS, and JavaScript. It is designed for free deployment on GitHub Pages.

## Files
- `index.html` — portfolio content and sections
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation, reveal animations, current year

## Publish free with GitHub Pages
1. Create a **public** repository named exactly `ImranNadeem444.github.io` (the username must match your GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will be `https://ImranNadeem444.github.io`.

## Before publishing
- Review the project descriptions and make sure each statement accurately reflects your work.
- Add a public CV file if you want a download button; this starter currently uses an email contact link instead.
- Replace GitHub links with individual repository URLs when you want to highlight specific public repositories.
- Only share client work and code that you are permitted to publish.
- This static site does not run Python/FastAPI backends or host large AI models. Link to separately deployed demos where available.

## Local preview
Open `index.html` in your browser. For a more consistent local server, run `python -m http.server 5500` in this folder and visit `http://localhost:5500`.
